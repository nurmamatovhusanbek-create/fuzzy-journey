# Texts for a native speaker to review (Russian and Uzbek)

The Russian and Uzbek of everything below was written by Claude without a native check. English is the source. Keys are in `godot/data/i18n/{en,ru,uz}.json`.

| Area | Keys |
|---|---|
| Build picker | `bl_*`, `bp_*` (levels, busy, upgrade) |
| Colonies and requirement lists | `colony_need_*`, `need_men`, `need_dp`, `err_unknown`, `err_project_busy`, `err_workers`, `err_calm`, `cc_requires` |
| Development projects | `pj_*`, `proj_need_*`, `invest_*`, `e_project*` |
| Country plate and standing | `cp_*`, `dv_standing` |
| Agents | `spy_survey`, `sp_easy`, `dv_far`, `err_nocontact`, `err_toofar`, `contact_*`, `e_spy_*`, `spy_cut_*`, `sp_*`, `spy_guard*` |
| Help ("How to play") | `codex_projects_*`, `codex_colonies_*`, `codex_standing_*`, `codex_agents_*` |

Historical province names: `godot/data/i18n/hist_ru.json`, `hist_uz.json` (English name -> localised), generated from `tools/hist/part*.py`. The English names and the era each applies to were written from memory and need a historian's check too.
