Buttons — six treatments

The brass gradient rectangle is a web-button with a gold coat. Each of these builds the button from the same parts as the dials and plates: a key you press down, a notched plate, a panel switch with a lamp, a ruled text link, a rubber stamp, and a punched ticket. Every card shows the three roles (primary, secondary, danger), disabled, forced hover / pressed / focus states, sizes, icon + keycap, hold-to-confirm, and the button in your Decree card. The first row is live: hover and press it.
