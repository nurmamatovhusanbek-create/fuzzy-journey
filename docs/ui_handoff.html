Terra Bellum — UI handoff

Turn-based grand strategy for Android / Windows / iOS. Godot 4.4.1 (GDScript, GL Compatibility). The mechanics are finished; the work left is the interface and visual layer only. This page describes the interface as it is on branch claude/ecstatic-gauss-f495v8, how it is built, how to run and test it, and what is not done yet.

1. Rules for whoever edits this

  • Interface layer only. No gameplay changes. Wire to existing data and functions (TBGame, TBOrderFlow, TBModals …).
  • Every visible string goes through the translation function (T.call("key") / TBI18n.T). Add keys to reference/i18n/{en,ru,uz}.js, then run node tools/i18n.mjs (it regenerates godot/data/i18n/*.json). Russian and Uzbek strings are longer: nothing may clip.
  • Tokens only. Colours come from TBTokens (godot/src/ui/ui_tokens.gd); tests/ui_lint_tokens.gd fails on raw colours, tests/ui_contrast.gd checks contrast pairs.
  • The title / main menu must not change (globe turning inside a graduated bezel ring, serif Cinzel/Alegreya, umber + brass palette). It is isolated by flags — see “Title screen”.
  • No text under 12 px. No hotkey letters drawn over labels (separate keycap). Tabular numbers for all figures. Motion = transform/opacity only and must respect TBKit.motion_ok() (reduced motion).
  • Typed-variable GDScript warnings are errors in this project. After adding a script or font run godot --headless --path godot --import.
  • Develop on claude/ecstatic-gauss-f495v8; no pull request unless asked.

2. What it looks like now

Known visual issue: when the player's nation is red, the accent (“signal”) reads like the semantic “bad” red (see the red primary button and own-army rings above). Needs a decision: shift accent hue away from red, or give “bad” a distinct treatment.

5. Map layer

The whole map is one fragment shader (godot/src/render/globe.gdshader, globe + flat equirect) driven by TBMapView (map_view.gd). Labels, army tokens, order arrows and focus rings are drawn by TBMapLabels (map_labels.gd) on top. Colours come from TBLenses (lenses.gd).

  • Atlas look is on when TBLenses.dark_land (set by main._enter_game_visuals()) and standard theme and not high-contrast: map.atlas_look() → shader uniform atlas = 1.
  • Ocean: sea-900, 15° graticule 0.5 px in sea-700, 6 px coastal glow (probe loop, ~8–24 texture reads per sea pixel).
  • Borders: nation 1.5 px in the pixel's own fill ×0.65; province 1 px at 20 % black (fades with zoom); coast 1 px at 40 % black. War front hatch / ally / truce patterns kept (colour-vision safe, strong uniform).
  • Player territory: 2 px inner stroke in the accent (signal_owner, signal_col).
  • Hover: fill +8 % lightness. Selection: fill +8 % and a 2 px paper-100 outline with marching dashes (6 on / 4 off, 1.2 s; anim_t, marching = 0 under reduced motion).
  • Land colours: each nation colour is clamped in OKLCH (chroma 0.06–0.12, lightness 0.42–0.62) and neighbouring nations are separated to ΔE ≥ 12 by hue rotation in 15° steps (TBLenses._atlas_nations()); the player's own hue is never rotated. Unowned land = slate #48505A (TBLenses.neutral()).
  • Nation labels: see Type above; two-line / first-word fallbacks and collision avoidance are in _draw_nation_names().
  • Army token (_draw_token()): 28 px (24 mid-zoom) ink-800 pill, 6 px stripe in the owner's colour on the left, 22×16 flag, number 14/600, ring = accent (own) / bad (hostile) / info (allied) / ink-500 (other) / paper-100 (selected, scale 1.08), round count badge for stacks. Far zoom tier = dots.
  • Not yet in Atlas style: order arrows (should be smooth dashed curves with an arrowhead + destination chip), legend card, parchment and high-contrast themes keep the old look on purpose.

7. Behaviour worth knowing

  • Selecting a province opens the inspector (right; bottom sheet on phones) and outlines the owner's border. Verbs are rows; the primary verb is a filled 44 px button with a keycap (M = move).
  • Orders: TBOrderFlow (Armed → Preview → confirm). Touch: tap target = preview, tap again = confirm. Mouse: left-click selects, right-click previews, right-click again confirms. Esc steps back one layer.
  • Destructive confirms (TBPanel.confirm(..., danger = true): declare war, delete/overwrite/load save, reset) use DangerBtn.make_hold(): hold 600 ms (progress bar along the bottom edge) or press Enter twice; a plain click shows “Hold to confirm”. Programmatic pressed.emit() no longer confirms — tests must emit confirmed.
  • Drawer opening calls TBPanel.drawer_opened_fn; below 1100 px it hides the inspector. Selecting a province below 1100 px closes drawers.
  • Text scale 100–200 % widens the inspector and wraps button labels; layouts are tested at 1.0 / 1.5 / 2.0.

8. Title screen isolation

The game and the title share code but not look. main.show_menu() sets K.serif = true, TBTokens.legacy = true, TBFrame.rounded = false, TBLenses.dark_land = false, forces the globe (map.set_mode(0)) and clears the owner outline. main._enter_game_visuals() flips all of them (sans fonts, Atlas palette, rounded corners, accent from g.color[human]) and rebuilds the theme. Never read K.serif/legacy from game widgets; never use game tokens in menu_parts.gd.
